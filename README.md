# Solana Mini Game

A browser-based Solana mini-game built with JavaScript, Express, and SPL token reward mechanics.

## Features

- Browser-based gameplay
- Score + streak system
- Dynamic difficulty scaling
- Shareable result cards
- Token reward backend
- Solana-inspired game loop

## Tech Stack

- JavaScript
- HTML/CSS
- Express.js
- Node.js
- Solana local validator
- SPL Tokens

## Run Locally

```bash
npm install
node server.js
```

Then open:

http://localhost:3000
